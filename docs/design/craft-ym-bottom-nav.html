Jewelry lives in content and sample data, never in navigation. Shown in every active state; the icon set is defined once and reused across all screens.

Layout, per PRD

Home · Products · + · Materials · Costs. The "+" is always "new product" — a flat, gently-rounded clay square on the baseline with the rest. Primary through colour alone; no lift, no shadow, no FAB. Settings stays off the nav, reached by the gear on Home.

Active state — three signals, quiet

Active tab gets a clay top-tick (echoing the pricing block's top rule), clay icon stroke, and a heavier clay label. No background pill, no fill — Linear restraint. The tick is the same 2px clay device used for the decision surface, so "where you are" and "where you decide" share one visual language.

Icons — neutral by design

Chrome carries no branch signal: tag, layers, wallet, house — a maker of candles or ceramics reads them the same. Jewelry stays where it's swappable: sample products, materials in grams of silver, labour steps like "Soldering". The nav never has to be redrawn to change trade. Lucide set (open-source, ISC), single-weight 1.6px.

Build notes

Icons ship as inline SVG (crisp at any density, colour via stroke). Bar sits flat on the page with a hairline top — no shadow — consistent with r3. Touch targets are the full 44px+ column, not just the glyph. Labels always shown; no icon-only mode.
