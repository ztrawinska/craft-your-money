Duplicate — the jewellery case

Makers build variants: the same ring in another size, the same setting with a different stone. Duplicate copies everything including the final price and saves it as a new draft named "… (copy)". Draft, because a copy is a starting point — it shouldn't silently join your active range or your dashboard metrics.

Archive ≠ delete

They differ in kind, so they're separate actions. Archive means "I stopped making this" — the record and its costs survive, it leaves the default overview and all dashboard metrics, and it can be restored. Delete means "this shouldn't exist".

Delete offers the gentler path

The confirm names the product, states plainly that it's permanent, and points at archive as the alternative — because most people reaching for delete actually mean archive. Warnings help; they don't just block.

No new screen for the archive

Archived products live behind the status dropdown we already built — one more option beside Healthy, Caution, Risky, No price, Draft. No extra nav tab, no settings page, nothing new to learn.

A sheet, not a floating menu

The action list is a bottom sheet, not a popover: no floating card on a flat page, full-width 44px+ targets, and it works the same by tap on any screen size. The delete confirm stays inside the same sheet — consistent with our inline-confirm pattern, never a stacked modal.

Data model already allowed for this

Product carries an archived flag in the spec — it just had no interface. This closes that gap rather than adding a new concept. Deletion is a real removal; archiving flips the flag.
